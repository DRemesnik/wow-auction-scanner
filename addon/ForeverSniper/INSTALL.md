# Goblin Broker: Forever (`ForeverSniper`) v2.0.0.16 — Установка и быстрый старт

## 1. Установка аддона
1. Скачайте и распакуйте архив **`ForeverSniper-v2.0.0.16.zip`**.
2. Скопируйте папку **`ForeverSniper`** в каталог аддонов вашего клиента WoW:
   ```text
   <Путь_к_WoW>\_forever_\Interface\AddOns\ForeverSniper\
   ```
   Внутри папки должны лежать: `ForeverSniper.toc`, `ForeverSniper.lua`, `Bindings.xml`, `logo.tga`.
3. Полностью перезапустите WoW (или введите `/reload`, если клиент уже был открыт, а файлы обновлены).
4. На экране выбора персонажа откройте **Модификации** и убедитесь, что **Goblin Broker: Forever Sniper** включён.

## 2. Как открыть аддон в игре
- Автоматически открывается вместе с окном Аукциона.
- Кнопка **`GB`** на **миникарте** (ЛКМ — открыть/скрыть, ПКМ + перетаскивание — переместить).
- Кнопка **`Goblin Broker`** в правом верхнем углу окна Аукциона.
- Чат-команды: `/gbroker` или `/fsniper`.

## 3. Быстрый старт (Настройка → Скан → Покупка)
1. **Добавьте цель** (любым из 3 способов):
   - Перетащите предмет из сумки на иконку предмета в аддоне;
   - Кликните в поле `ID предмета` и нажмите `Shift + ЛКМ` по предмету в сумке;
   - Или нажмите `Экспорт в аддон` в веб-дашборде → `Импорт из дашборда` в аддоне.
2. Задайте **Макс. цену** (`з / с / м`) и при желании **Лимит покупки (шт)** (остаток будет автоматически уменьшаться после каждой покупки).
3. Нажмите **Старт скан** (при открытом АХ).
4. Назначьте клавишу (например, колесо мыши) в **Настройки → Назначение клавиш → Goblin Broker: Forever → Купить / Подтвердить лот**.
   - Штучные предметы покупаются **в 1 клик**;
   - Стаковые товары (*Commodities*) — **в 2 быстрых нажатия** (`Start` → `Confirm`).
